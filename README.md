# Expense Vision

**Expense Vision** — Android-приложение для учёта расходов по чекам. Сканируешь бумажный чек — приложение распознаёт текст прямо на устройстве, извлекает сумму, дату и магазин, предлагает категорию траты и сохраняет запись в локальную базу. Полностью офлайн: без интернета и без передачи данных на сервер.

## Возможности

- 📷 **Сканирование чека** — камера с автоопределением границ документа и автоматическим выравниванием/кадрированием.
- 🔍 **OCR на устройстве** — распознавание русского текста чека, включая кириллицу, без сети.
- 🧾 **Извлечение данных** — дата, итоговая сумма, магазин/место покупки.
- 🏷️ **Категоризация трат** — автоматическое определение категории по ключевым словам: продукты, кафе и рестораны, транспорт, аптека, развлечения и др.
- ✏️ **Экран подтверждения** — все распознанные поля можно проверить и поправить перед сохранением.
- 💾 **Локальное хранение** — чеки хранятся в базе на устройстве.
- 📊 **История и статистика** — список чеков, фильтр по категориям, суммы за период.

## Как это работает

1. **Скан.** Пользователь нажимает «Сканировать чек». Сканер документа находит края чека, выравнивает и кадрирует изображение.
2. **Распознавание.** Изображение проходит через OCR-движок: детекция текстовых блоков → распознавание каждой строки.
3. **Разбор.** Из текста извлекаются дата, итоговая сумма и магазин; по ключевым словам подбирается категория.
4. **Подтверждение.** Пользователь проверяет и при необходимости редактирует поля.
5. **Сохранение.** Чек записывается в локальную базу с привязкой к дате и категории.

## OCR: почему именно так

Главное требование — корректное распознавание **русских чеков**. Google ML Kit Text Recognition не поддерживает кириллицу, поэтому в основе лежит **PaddleOCR (PP-OCRv5)** — одна из лучших открытых моделей для кириллицы. Она работает на устройстве через **ONNX Runtime**, а пред- и постобработка (детекция рамок, CTC-декодирование, перспективное кадрирование) реализованы на Kotlin. Вся обработка локальная — данные не покидают устройство.

## Архитектура

Многомодульный проект по принципам Clean Architecture:

```
:app                  точка входа, DI, навигация
:core:model           доменные модели, парсер полей, категоризатор (чистый Kotlin)
:core:database        Room: сущности, DAO, репозитории
:core:ocr             OCR-движок (PaddleOCR + ONNX Runtime + OpenCV)
:core:designsystem    тема и общие UI-компоненты
:feature:scan         сценарий сканирования и подтверждения
:feature:receipts     история и статистика по категориям
```

Зависимости направлены в сторону `:core:model`; сам он не зависит от Android и покрывается unit-тестами.

## Технологии

| Слой | Решение |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3 |
| OCR | PaddleOCR (PP-OCRv5) + ONNX Runtime |
| Обработка изображений | OpenCV |
| Сканирование | ML Kit Document Scanner |
| Хранение | Room |
| DI | Hilt |
| Навигация | Navigation Compose |

## Сборка и запуск

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

**Требования:** Android SDK, JDK 17, устройство с Google Play Services (необходим для сканера документов).
